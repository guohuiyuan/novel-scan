# 效果示例

这里放的是 **真实跑完的完整产物**，原样保留、未做人工润色。

| 示例 | 输入 | 产物 |
|---|---|---|
| [都市良人行](都市良人行/README.md) | 111 万字 / 290 章 / 5 卷（OCR 稿，含另一版本的重复收录） | 书评 md + 人物卡 md + 结构化 JSON + 封面 + 12 张人物图（男主 1 + 女主 11）+ 8 位配角 |

每个 `<书名>/README.md` 是那一次输出的导读：产物清单与「看什么」、书评开头长什么样、审计结果、如何用
`scripts/make_example.py` 生成自己的示例。

> 目录内的相对链接（`人物图/xx.webp`、`都市良人行_书评.md`）都以该示例目录为根，
> 在 GitHub 上点开图片/文件即可直接预览。新增示例时请把导读放在**示例目录内**，
> 不要放在 `examples/` 根下——否则图片路径会指到 `examples/人物图/`（曾经踩过）。
