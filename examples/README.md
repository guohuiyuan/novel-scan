# 效果示例

这里放的是 **真实跑完的完整产物**，原样保留、未做人工润色。

| 示例 | 输入 | 产物 |
|---|---|---|
| [我才不会被女孩子欺负呢](我才不会被女孩子欺负呢/README.md) | 461.3 万字 / 1365 章（GBK 稿，先转 UTF-8） | 书评 md + 人物卡 md + 结构化 JSON + 封面 + 10 张人物图（男主 1 + 女主 9）+ 出图基准联系表 |

这份既是完整产物样例，也是**出图基准**：10 张立绘里 9 张线条/上色/取景/背景同代，
`人物图/_联系表.webp` 可以直接当及格线对；`人物图/_图片索引.json` 是 `appearance_prompt` 的写法范例。

每个 `<书名>/README.md` 是那一次输出的导读：产物清单与「看什么」、书评开头长什么样、审计结果、如何用
`scripts/make_example.py` 生成自己的示例。

> 目录内的相对链接（`人物图/xx.webp`、`<书名>_书评.md`）都以该示例目录为根，
> 在 GitHub 上点开图片/文件即可直接预览。新增示例时请把导读放在**示例目录内**，
> 不要放在 `examples/` 根下——否则图片路径会指到 `examples/人物图/`（曾经踩过）。
