# 效果示例：《都市良人行》

这份目录是 novel-scan 在**真实输入**上跑完的一次完整输出，原样保留、未做人工润色——你可以据此判断
这个 skill 到底交付什么、细到什么程度，也方便拿自己的输出对照，看哪一步没做到。

- 输入：`都市良人行_禹岩_20261118_164915.txt`（OCR 稿，含"另一版本重复收录"，有效正文 110.9 万字 / 290 章 / 5 卷）
- 扫描：21 个分块笔记 + 11 位女主逐人回原文定向核验
- 产出：1 位男主 + 11 位女主 + 8 位配角；全书雷点 1 条、郁闷点 24 条
- 人物图：按书中外貌描写反推 prompt 生成（画师 `morikura_en`），**本目录已把 920×1536 原图降到 560 宽**，仅用于展示，单张 30-50KB

## 书评开头实际长这样

```
完结仙草：都市后宫 扮猪吃虎 圣门圣主 双生姐妹 111万字
[封面]
《都市良人行》 ｜ 作者：禹岩 ｜ 字数：约 111 万字 ｜ 290 章 ｜ 5 卷
题材：都市 异能 后宫 商战 ｜ 状态：完结 ｜ 平台：未知
```

标题不是人手写：结算词由总评档位换算（A-→仙草），题材取 `genre`，三个四字卖点来自
`book_meta.headline_tags`（这里 `扮猪吃虎` / `圣门圣主` / `双生姐妹` 都是书里能查证的事实）。

## 女主条目长这样（摘 #3 曾柔）

```
### 3. 曾柔
**身份**：师兄曾天元的次女、九号曾倩的双胞胎妹妹。
**外貌**：……
**经历**：……
**纯洁度**：处 ✅ ｜ 精神初 ✅ ｜ 初婚 ✅ ｜ 初摸 ✅ —— **全初**
**性格特点**：嘴硬心软、爱吃醋、说话直、认死理
> **名场面**：「你坏蛋，你混蛋，我恨死你了，我想你，我想你——」 —— 他失踪两年后回家，她扑上去又咬又哭
```

每条都要求：外貌必须来自原文描写（不许编）、纯洁度按四维逐项给（缺证据记未知，不许只写「全初」）、名场面台词逐字照抄（审计会回原文核验）、
行号一律不写进成品（只在 JSON 里留 `line_no` 供追溯）。

## 自己生成一份示例

```bash
python scripts/make_example.py \
  --src  /path/to/某本书的输出目录 \
  --dst  examples/某本书 \
  --max-width 560 --quality 82
```

它只做两件事：抄交付物、把人物图降采样（14.9MB → 0.9MB 以内）；默认再抽一份角色 JSON 和一份分块笔记，
`--no-intermediates` 可关掉。输出目录里的 `_prescan/`、`scan_notes/` 全量、`json/` 全量都不进仓库——
它们是中间产物，随书不同而膨胀。
