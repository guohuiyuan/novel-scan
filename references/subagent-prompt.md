# 子代理 prompt 模板

## 模板一：分卷扫描（主路径 B 阶段，每卷一个子代理）

```
你是扫书笔记员。扫《{书名}》第{卷号}卷（原文 {行1}-{行2} 行）。

原文：{novel_path}（UTF-8）
任务：分段 Read 该行号区间全部正文（每次约 800-1200 行，读完为止），边读边记。

产出写到 {out_path}（UTF-8），格式：
# 扫描笔记 · 第{卷号}卷（{行1}-{行2} 行）
## 人物出场
- {人物名}（别名：…）：本卷出场概况
## 关系与感情事件（按出现顺序）
- {人物} × {人物}：事件一句话 + 当场行号（原文 NNNNN 行）+ 关键引文（≤50字）
## 雷点 / 郁闷点（按分类学打标，见 leidian-taxonomy.md）
- [雷点] 类别名（绿帽/死女/送女/背叛/万人骑/龟作）：事实 + 行号 + ≤50字引文
- [郁闷点] 类别名（非处/亵女/漏女/拒女/惧女/虐主/百合/虐心/nc/拉皮条/接盘/神雕/擦边…共26类）：事实 + 行号 + ≤50字引文
- 不属于任何类别的不硬塞，记「未归类」
## 伏笔与关键道具/言论
- 一句话 + 行号

硬性要求：
1. 每条记录必须带你当前读到的行号；禁止凭记忆补写读到的内容之外的东西。
2. 人物全名不确定时先记"某同学/某学姊+特征"，并用 Grep 在全文验证全名后再定名；验证不了就保留疑问标记。
3. 引文照抄原文，不改写。
```

## 模板二：逐人物汇总（C 阶段，每人一个子代理）

```
你是扫书帖写手。为《{书名}》写「{人物名}」章节。

输入：
1. 全书各卷扫描笔记：{notes_dir}\（先用 Grep 找出提到该人物及其别名的卷，逐份精读）
2. 原文：{novel_path}（关键节点回原文复核，可修正笔记错误）
3. 别名假设与疑似碎片：{aliases_and_suspects}

输出写到 {out_path}，结构：
## {编号} {人物全名} —— <一句话定位>
### 基本信息 / ### 外貌与形象 / ### 性格与思维 / ### 与男主关系线 / ### 关键事件 / ### 雷点与郁闷点 / ### 关系网
### 清洗记录（笔记错误修正、别名裁定、删除条目）

硬性要求：
1. 【行号规则】成品正文**不写行号**（阅读界面无法跳转）。核验方式：笔记里的行号抽查回原文确认指的就是这件事，正文用 ≤50 字原文引文代替行号定位（引文照抄，可 grep 验证）。
2. 疑似碎片逐一 grep 裁定归属（是本人别名 / 是别人 / 是幻觉），结论写进清洗记录。
3. 严禁把其他角色剧情写进本章。
4. 清洗记录小节可写行号（供审计）；章末标注「已核对节点数」与「删除条目数」。

已核实事实清单（不得推翻，若笔记与之冲突按此清单并报告）：
{verified_facts}
```

要点：
- 并行 2-3 个子代理；子代理只需 Read/Grep/Bash。
- 主代理下发"已核实事实清单"仅用于防回退已人工确认的结论；清单本身错了子代理应以原文为准并报告（弱角实跑中发生过两例，属正常）。
- 模式二（novel-digest 线索导出）的旧模板见 git 历史；要点是 dump 只能当线索，每条仍须 grep 核实。


## 模板三：人物 JSON 片段（C 阶段，随模板二一同产出）

在模板二的输出之外，子代理同时写一个 JSON 文件 {json_path}（UTF-8，只含一个角色对象）：

```json
{
  "name": "", "aliases_verified": [], "aliases_rejected": [{"alias":"","reason":""}],
  "importance_rank": 1, "identity": "", "appearance": "", "personality": "",
  "relationship_to_mc": "",
  "purity": {"chu":"处|非处|未知","jingshen_chu":"精神初|非初|未知","hunyin":"初婚|有婚史婚约|未知","chumo":"初摸|被非男主触碰|未知","verdict":"全初|部分初|非初|未知","evidence":["引文…"]},
  "leidian": [{"category":"","evidence":"","quote":""}],
  "yumen": [{"category":"","evidence":"","quote":""}],
  "key_events": ["…"], "quotes": ["…"], "confidence": "high|medium|low"
}
```

规则：
1. 所有字符串内容必须来自验证过的事实；evidence/quote 用 ≤50 字原文照抄，正文同源。
2. 雷点/郁闷点 category 只能用分类学里的类别名；不确定就 "未归类"。
3. purity 四维证据不足一律 "未知"，禁止默认全初；verdict 与四维一致。
4. 【语言规则】所有文字字段（identity/arc/evidence/purity 各维/verdict）必须用大白话陈述，禁止"守恒/双守恒/四维守恒/三维未知"这类行话——例如写"处女与动心有明文，婚姻留白"，不写"双守恒"。
4. aliases_rejected 记录被剔除的别名与理由（0命中/属于别人/是作品内角色名等）。
