# 雷点/郁闷点分类学（扫书判定唯一标准）

> 这是**男性向网文读者视角的毒点分类学**，不是"读起来难受的情节"。
> 雷点=会直接弃书的严重缺陷（6 类）；郁闷点=不至于弃书但引起不适/纠结的情节（26 类）。
> 记录规则：每条雷点/郁闷点必须标**类别名**+一句事实+≤50字引文；不属于任何类别的不硬塞，宁可记"未归类"。

## 术语表（glossary）

- **初**：女主满足"初次"标准——①精神初：除男主外未对任何男性动心；②肉体初：除男主外未与任何男性有亲密身体接触。包含前世情况。
- **处**：处女。

## 雷点（严重毒点，6 类）

| 类别 | 定义 |
|---|---|
| 绿帽 | 【仅限男主视角】女主与非男主男性发生肢体接触或暧昧（含被强迫）；也包括主角被女性绿。**绝对排除**：男主与其他女性（含女主的母亲/姐妹/女儿/闺蜜）发生关系属"后宫/推土机"，绝不标绿帽 |
| 死女 | 女主/准女主死亡：无复活可能；或虽有复活可能但死法猎奇；或结尾主角独自长生而女主生老病死 |
| 送女 | 男主把女主/高戏份准女主拱手送给配角（男主收后宫不算送女） |
| 背叛 | 女主背叛男主：为集团利益出卖（未洗白则雷）/身在曹营心在汉/身心皆背叛转投他人 |
| 万人骑 | 与许多男性发生过关系、自己都记不清的女子（个别多次嫁人的人妻不在此列） |
| 龟作 | 作者知雷写雷：刻意把某女主前世写成被强迫后变万人骑；或把八成女主前世描绘成非处/万人骑 |

## 判定输出格式（笔记与人物 JSON 通用）

```
- [雷点|郁闷点] 类别名：一句事实描述（引文「……」≤50字）
```

- 雷点/郁闷点是**全书级结论**，但证据挂在具体角色上。
- 纯洁度四维判定口径：**处**（肉体处女？）/ **精神初**（对非男主动过心？）/ **初婚**（无婚史婚约？）/ **初摸**（未被非男主触碰身体？）。证据不足默认"未知"并写明缺什么证据，禁止默认全初。
